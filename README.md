# منتجع رُومة | Ruma Resort

موقع إلكتروني متكامل لمنتجع رُومة، يتضمن واجهة أمامية عربية (RTL) بتصميم فاخر وهادئ،
ونظام حجوزات حقيقي، ولوحة تحكم إدارية آمنة، مبني على Flask في الخلفية.

---

## 1. وصف المشروع

يتيح هذا المشروع:

- عرض معلومات المنتجع، الأسعار، الخدمات، ومعرض الصور بتصميم عربي فاخر ومتجاوب.
- نظام حجز حقيقي: يرسل الزائر طلب حجز، ويحصل على رقم حجز فريد (مثل `RUMA-A1B2C3`)،
  ويمكنه لاحقاً التحقق من حالة حجزه.
- لوحة تحكم إدارية محمية بكلمة مرور لإدارة الحجوزات، الأسعار، معلومات المنتجع، ومعرض الصور.
- بنية منفصلة بين الواجهة الأمامية (يمكن نشرها على GitHub Pages) والخلفية (Flask، تُنشر على استضافة بايثون منفصلة).

## 3. كيفية الاستنساخ (Clone)

```bash
git clone https://github.com/YOUR-USERNAME/ruma-resort.git
cd ruma-resort
```

---

## 4. التثبيت

### الخلفية (Backend)

```bash
cd backend
python3 -m venv venv
source venv/bin/activate          # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

### الواجهة الأمامية (Frontend)

لا تحتاج أي تثبيت — ملفات HTML/CSS/JS ثابتة بالكامل.

---

## 5. إعداد ملف .env

انسخ ملف الأمثلة وعدّل القيم:

```bash
cd backend
cp .env.example .env
```

ثم افتح `backend/.env` وعدّل:

| المتغير | الوصف |
|---|---|
| `SECRET_KEY` | مفتاح سري عشوائي وطويل لحماية الجلسات — غيّره حتماً قبل النشر |
| `ADMIN_USERNAME` | اسم المستخدم الإداري الافتراضي |
| `ADMIN_PASSWORD` | كلمة مرور المستخدم الإداري الافتراضي (غيّرها فوراً بعد أول تشغيل) |
| `FRONTEND_ORIGIN` | نطاق الواجهة الأمامية المسموح له بالاتصال بالـ API، مثل `https://your-username.github.io` |
| `DATABASE_URL` | اختياري — رابط قاعدة بيانات بديلة (PostgreSQL مثلاً)، افتراضياً SQLite محلي |

**لا تقم أبداً برفع ملف `.env` إلى GitHub** — وهو مستثنى مسبقاً في `.gitignore`.

---

## 6. تشغيل الواجهة الأمامية محلياً

يمكنك فتح `frontend/index.html` مباشرة في المتصفح، أو تشغيل خادم بسيط:

```bash
cd frontend
python3 -m http.server 8080
```

ثم افتح `http://127.0.0.1:8080`.

---

## 7. تشغيل خلفية Flask محلياً

```bash
cd backend
source venv/bin/activate
export FLASK_APP=app.py          # على ويندوز: set FLASK_APP=app.py
python3 app.py
```

سيعمل الخادم على `http://127.0.0.1:5000`. عند أول تشغيل، سيقوم التطبيق تلقائياً بـ:

- إنشاء قاعدة البيانات وجداولها.
- إنشاء المستخدم الإداري باستخدام `ADMIN_USERNAME` و `ADMIN_PASSWORD` من `.env`.
- تعبئة الإعدادات الافتراضية (الأسعار، معلومات المنتجع).

---

## 8. نشر الواجهة الأمامية على GitHub Pages

الطريقة تلقائية عبر GitHub Actions:

1. في إعدادات المستودع على GitHub: `Settings > Pages > Build and deployment > Source` اختر **GitHub Actions**.
2. عند كل `git push` إلى فرع `main`، سيقوم الـ workflow الموجود في
   `.github/workflows/deploy-pages.yml` تلقائياً بنشر محتوى مجلد `frontend/` كموقع GitHub Pages.
3. سيكون الموقع متاحاً على: `https://YOUR-USERNAME.github.io/ruma-resort/`.

> **ملاحظة مهمة:** GitHub Pages يستضيف ملفات ثابتة فقط ولا يمكنه تشغيل Flask. لذلك يجب نشر الخلفية (backend) بشكل منفصل — راجع القسم التالي.

---

## 9. نشر الخلفية (Backend)

انشر مجلد `backend/` على أي استضافة تدعم بايثون، مثل:

- **Render** / **Railway** / **Fly.io**: أنشئ خدمة ويب جديدة، اربطها بالمستودع، حدد المجلد `backend`،
  أمر التشغيل: `gunicorn wsgi:app --bind 0.0.0.0:$PORT`.
- **PythonAnywhere**: ارفع الكود، ثم اضبط WSGI ليشير إلى `backend/wsgi.py`.
- **VPS خاص**: استخدم `gunicorn` خلف `nginx` كـ reverse proxy.

في جميع الحالات:

1. اضبط متغيرات البيئة (`SECRET_KEY`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `FRONTEND_ORIGIN`) من لوحة تحكم الاستضافة، وليس بترك ملف `.env` داخل الكود.
2. تأكد من `SESSION_COOKIE_SECURE=true` عند التشغيل خلف HTTPS.

---

## 10. ربط الواجهة الأمامية بالخلفية

بعد نشر الخلفية والحصول على عنوانها العام (مثل `https://ruma-api.onrender.com`):

1. افتح `frontend/js/config.js`.
2. عدّل القيمة:

```js
window.RUMA_CONFIG = {
  API_BASE_URL: "https://ruma-api.onrender.com",
};
```

3. احفظ، ثم ادفع (`git push`) — سينشر GitHub Actions النسخة المحدثة تلقائياً.

---

## 11. ضبط API_BASE_URL

`API_BASE_URL` هو المكان الوحيد الذي يحدد عنوان الخادم الذي تتحدث معه الواجهة الأمامية.
غيّره في `frontend/js/config.js` فقط — دون الحاجة لتعديل أي ملف آخر.

---

## 12. إنشاء / إعادة ضبط حساب المدير

الحساب الأول يُنشأ تلقائياً من `ADMIN_USERNAME` و `ADMIN_PASSWORD` عند أول تشغيل.
لإعادة إنشائه أو تغيير كلمة المرور لاحقاً:

```bash
cd backend
flask --app app create-admin
```

سيقوم هذا الأمر بإنشاء الحساب إن لم يكن موجوداً، أو تحديث كلمة مروره بالقيمة الحالية في `.env`.

تسجيل الدخول للوحة التحكم من: `http://127.0.0.1:5000/admin/login` (أو عنوان الخلفية بعد النشر).

---

## 13. تغيير الأسعار ومعلومات المنتجع

من لوحة التحكم: **الأسعار والمعلومات** (`/admin/settings`) — يمكنك تعديل:

- سعر وأوقات الشفت الصباحي والمسائي.
- اسم ووصف المنتجع.
- رقم الهاتف وواتساب.
- قائمة الخدمات المعروضة في الصفحة الرئيسية.

تُحفظ هذه القيم في قاعدة البيانات وتُعرض تلقائياً في الواجهة الأمامية عبر `/api/settings`.

---

## 14. إدارة الحجوزات

من لوحة التحكم: **الحجوزات** (`/admin/bookings`) يمكنك:

- البحث بالاسم أو رقم الهاتف أو رقم الحجز.
- التصفية حسب الحالة: جديد، قيد المراجعة، مؤكد، مرفوض، مكتمل.
- فتح تفاصيل أي حجز، تغيير حالته، أو حذفه نهائياً.

الحجوزات **لا تُؤكَّد تلقائياً** — كل حجز يبدأ بحالة "جديد" وينتظر مراجعة الإدارة.

---

## 15. رفع صور معرض الصور

من لوحة التحكم: **معرض الصور** (`/admin/gallery`):

1. اختر صورة (الصيغ المدعومة: `png`, `jpg`, `jpeg`, `webp`، بحد أقصى 6 ميجابايت).
2. أضف وصفاً اختيارياً.
3. اضغط "رفع الصورة" — ستظهر فوراً في معرض الصور بالصفحة الرئيسية عبر `/api/gallery`.

يمكنك حذف أي صورة بضغطة واحدة من نفس الصفحة.

## الأمان

- كلمات المرور مشفّرة (hashing) عبر Werkzeug، ولا تُخزَّن أبداً كنص صريح.
- جلسات الدخول محمية عبر Flask-Login، وجميع مسارات لوحة التحكم محمية بـ `@login_required`.
- نماذج لوحة التحكم محمية بـ CSRF token عبر Flask-WTF.
- التحقق من صحة المدخلات (input validation) في جميع نقاط API العامة.
- رفع الصور يخضع لفحص الامتداد، تسمية آمنة عشوائية للملفات، وحد أقصى لحجم الملف.
- لا يوجد أي سر أو كلمة مرور داخل الكود — كل شيء عبر متغيرات البيئة.
